section: Changed
---
A console or bulk command whose arguments the audit hides (it logs them as "Name ***") now says in its confirmation which way it goes to the device, before anything is sent: over MQTT "The command goes to the device over the MQTT broker, unencrypted; the broker also delivers it to every client subscribed to this device's commands (a broker ACL prevents that)." (with an ssl://, tls:// or mqtts:// broker URL "encrypted from TasmoFleet to the broker" instead of "unencrypted"), over HTTP "The command goes to the device over HTTP, unencrypted.". The console asks for every such command, also one that sent at once before; the bulk preview shows one row per transport with how many of the chosen devices take it (and a "Not sent" row for devices whose HTTP is not reachable when MQTT does not carry the command, such as Json or a rule text). The command goes only the way it named: if the way to the device or the broker URL changes before the send, nothing is sent and the console asks again (a bulk run sends nothing and asks you to start again from the device list); a bulk job and its retry keep the way their preview named (#826)
