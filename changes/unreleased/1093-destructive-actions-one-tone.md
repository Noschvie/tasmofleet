Destructive actions confirm the same way everywhere: the confirming button is red and repeats the action with its object ("Power off 6 devices", "Restore backup", "Cancel remaining") in the dialog and on the page without JavaScript, which used to disagree (Cancel remaining was blue in the dialog and red on its page; Restart, Restore and Power off were blue). The dialog and its page ask the same question, a confirmation page no longer repeats its title in a card heading, and a destructive dialog opens with the focus on Cancel instead of on the first button in it. The console's quick Restart 1 opens the restart confirmation instead of sending at once (the typed command line is unchanged), the rules list has one delete dialog instead of one per rule, a cached firmware file is deleted from its row menu with "Delete N unused" below the list, and Deactivate is a default button in the user page and the row menu alike. The triggers of Reset settings, Restart, Restore, Delete and Deactivate lose the "…" they never needed (#1093)
