section: Changed
---
The files of a backup over MQTT now come over MQTT too when the device's firmware was built with `USE_UFILESYS_MQTT` (Tasmota arendst/Tasmota#25278, not in the stock builds) and has no SD card: the listing and every file on the device's topic, with no request to its address, so remote devices reached only over MQTT keep their files. A stock firmware still sends its files over HTTP only; when that address cannot be reached, the backup now says why ("they need HTTP (this firmware sends no files over MQTT), and HTTP could not be used: …") instead of only "the device took too long to answer", although a device whose HTTP has never answered still waits for that one timeout per backup. The Files fold says which way the files were read. File contents and the MQTT password then cross the broker like the settings dump, and the broker ACL notices and the device's Back up line say so: restrict the device topics with a broker ACL (#924, thanks @Noschvie)
