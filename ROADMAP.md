# Roadmap

The plan up to 0.46, one theme per minor release, in the order they ship. Each release is a
[GitHub milestone](https://github.com/hellwand/tasmofleet/milestones) with the full list of issues; this file
says what each one is about. No dates. Bug fixes and small changes go into the next release as they come,
without changing the plan.

## Towards 1.0

Not tied to a release yet:

- **Security review** of the authentication, restore and command paths, before 1.0.
- **Push upload for ESP8266.** Push upload (the update is sent to the device instead of the device downloading it) works on ESP32. On ESP8266 it is still refused, and those devices download; it follows after a test on real hardware.
- **1.0** means a stable configuration and stable routes. From then on, breaking changes come only in major versions.

New ideas start in the [Backlog](https://github.com/hellwand/tasmofleet/milestone/13) and move into a release when they are planned.
